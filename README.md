# archive-for-news

新闻存档库。按地区与主题分为 8 个板块：

| 目录 | 收录范围 |
|---|---|
| `美国/` | 美国政治、政策、对华动作（BIS/OFAC/FCC/USTR 等） |
| `欧洲/` | 欧盟及欧洲各国政治、经济、对华关系 |
| `中东中亚/` | 中东、海湾、中亚各国局势 |
| `俄乌/` | 俄乌战争及相关制裁、外交动态 |
| `亚太/` | 日韩、东南亚、南亚、澳新等地区动态 |
| `拉美/` | 拉丁美洲各国政治经济动态 |
| `科技/` | AI、半导体、出口管制科技线、企业动态 |
| `国内/` | 中国国内政策、经济、社会动态 |

## 约定

- 每条新闻一个文件，命名建议：`YYYY-MM-DD-标题简写.md`
- 文件内保留：标题、日期、来源（官方/权威媒体优先）、原文链接、要点摘录
